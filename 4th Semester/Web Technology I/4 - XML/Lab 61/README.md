# Lab 61: Student List XML Document

## Objective
Create a simple XML document that represents a list of students, where each student has the following details:
- name
- roll number
- department
- year

Display the XML tree structure.

## Files
- `students.xml` - Contains student data in XML format

## XML Structure
```
students
├── student
│   ├── name
│   ├── rollNumber
│   ├── department
│   └── year
├── student
├── student
... (more students)
```

## How to View
- Open `students.xml` in any XML viewer or web browser
- The tree structure shows the hierarchy of elements
