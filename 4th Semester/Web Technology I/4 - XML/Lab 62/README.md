# Lab 62: Book Catalog XML Document

## Objective
Create an XML file for a book catalog. Each book should contain:
- title
- author
- publisher
- price
- ISBN

Ensure proper syntax and nesting.

## Files
- `books.xml` - Contains book catalog data in XML format

## XML Structure
```
bookCatalog
├── book
│   ├── title
│   ├── author
│   ├── publisher
│   ├── price
│   └── isbn
├── book
├── book
... (more books)
```

## Key Points
- All elements are properly nested
- ISBN format includes standard book identifiers
- Prices are in decimal format
