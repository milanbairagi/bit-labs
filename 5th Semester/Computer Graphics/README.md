# How to Run the Program

## Linux

Use the following steps to compile and run the program:

1. Run the command below.
2. Replace `lab-1.cpp` with your source filename.

```bash
g++ lab-1.cpp -lglfw -lGL -o lab-1 && ./lab-1
```

## Windows (MinGW)

Use the following steps to compile and run the program on Windows:

1. Run the command below.
2. Replace `lab-1.cpp` with your source filename.

```powershell
g++ lab-1.cpp -lglfw -lopengl32 -o lab-1.exe; .\lab-1.exe
```
